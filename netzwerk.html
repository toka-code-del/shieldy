🌐 Netzwerk

Netzwerke verbinden Computer, Smartphones, Server und viele weitere Geräte miteinander. Ohne Netzwerke wäre das Internet, Online-Gaming, Cloud-Speicher oder das Versenden von Nachrichten nicht möglich. In einem Netzwerk werden Daten zwischen Geräten ausgetauscht und an die richtigen Ziele weitergeleitet.

📡 Router

Ein Router verbindet verschiedene Netzwerke miteinander und ermöglicht den Zugriff auf das Internet. Er leitet Datenpakete an das richtige Ziel weiter.

Fast jeder Haushalt besitzt einen Router, der das Heimnetzwerk mit dem Internet verbindet.

🔄 Switch

Ein Switch verbindet mehrere Geräte innerhalb eines lokalen Netzwerks. Er erkennt, welches Gerät die Daten empfangen soll und sendet diese gezielt weiter.

Dadurch arbeitet ein Switch effizienter als ältere Netzwerkgeräte wie Hubs.

🏠 IP-Adresse

Jedes Gerät in einem Netzwerk benötigt eine eindeutige IP-Adresse. Sie dient als digitale Adresse, damit Daten an das richtige Gerät gelangen.

Beispiel: 192.168.1.25

📚 OSI-Modell

Das OSI-Modell besteht aus sieben Schichten und beschreibt, wie Daten in Netzwerken übertragen werden.

Es hilft dabei, Netzwerkprobleme leichter zu analysieren und zu verstehen.

💡 Shieldy Tipp

Verwende sichere WLAN-Passwörter und aktualisiere regelmäßig die Firmware deines Routers. Dadurch können bekannte Sicherheitslücken geschlossen werden.
